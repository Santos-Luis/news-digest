**AI Tools & Developer Utilities**
Anthropic's Claude Agent SDK is getting a usage model change: starting June 15, Agent SDK and `claude -p` usage on subscription plans will draw from a separate monthly Agent SDK credit pool, distinct from interactive usage limits — a sign Anthropic is treating programmatic agent use as a distinct product tier. Separately, the newly launched Managed Agents API (currently in beta) lets developers offload the entire agent loop and sandbox to Anthropic's infrastructure, shifting the operational burden off self-hosted processes. [Claude Agent SDK Docs](https://platform.claude.com/docs/en/managed-agents/overview)
