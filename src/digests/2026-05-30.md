**Enterprise AI & AI Strategy**

Gartner warned this month that by 2027, half of enterprises without a people-centric AI strategy will lose their top AI talent to competitors who invest in workforce enablement — a prediction that puts the spotlight on the gap between AI deployment and organizational readiness. The warning lands alongside a separate HCLTech report showing 43% of enterprise AI initiatives are at risk of failure, with leaders citing shrinking timelines and unclear accountability structures. Only 29% of organizations report significant ROI from generative AI today, suggesting the current wave of investment is running ahead of execution capability. **AI Tools & Developer Utilities**

Anthropic released Claude Opus 4.7, which resolves 3x more production software tasks than Opus 4.6 on Rakuten-SWE-Bench, alongside new Managed Agents capabilities including cross-session memory (now in public beta), multiagent orchestration, and webhook-driven workflows aimed at enterprise teams building long-running agents. The release follows the Code with Claude 2026 conference in early May, where Anthropic made the point that the majority of code written internally is now produced by Claude Code — a notable shift in how they frame the product's role. The memory feature in particular is drawing attention, as portable agent memory stores with audit logs address one of the main enterprise blockers for deploying stateful AI agents at scale.
