**Enterprise AI & AI Strategy**

Enterprise AI is hitting a cost crisis: Uber burned through its entire 2026 AI budget by April, and a new analysis finds that each autonomous agent deployed increases a company's attack surface by over 450% relative to a human user doing equivalent work. Against that backdrop, only 42% of organizations report cross-departmental AI adoption with measurable impact despite 91% of IT executives being bullish — the execution gap is widening even as AI budgets continue to grow. **AI Tools & Developer Utilities**

Chinese lab MiniMax released M3, the first open-weights model to combine frontier-tier coding (59% on SWE-Bench Pro, beating GPT-5.5), a 1-million-token context window, and native multimodal computer use in a single 428B-parameter architecture. The model is accessible via API now, though training code hasn't been released — putting it in the increasingly common "open-weights but not open-source" category that is reshaping what "open AI" means.
