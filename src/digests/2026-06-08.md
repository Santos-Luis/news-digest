OpenAI separately reports enterprise now accounts for over 40% of revenue and is on pace to match consumer revenue by year-end. **AI Tools & Developer Utilities**
Starting June 15, Claude Agent SDK and Claude Code GitHub Actions usage will be metered separately from interactive Claude Code subscriptions, shifting to a per-token credit model ($20/month for Pro, $100–$200 for Max tiers). Alongside the billing change, Anthropic unveiled new Managed Agents capabilities: "Dreaming"—a scheduled process that reviews past agent sessions and curates memory to improve future runs—and multiagent orchestration, where a lead agent delegates parallel work to specialist subagents on a shared filesystem with full traceability via the Claude Console.
