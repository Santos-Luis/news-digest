**Software Engineering & Architecture**
GitHub Copilot's autonomous coding agent reached general availability this week, enabling developers to assign a GitHub Issue directly to Copilot, which then spins up a sandboxed GitHub Actions environment, writes code, runs tests, and opens a pull request for review — entirely in the background. The agent also integrates with Copilot's code review flow, which can now route its own suggestions back to the coding agent to auto-generate fix PRs. Starting June 1, Copilot drops its premium-request-unit model in favour of usage-based AI Credits billing. [GitHub Blog](https://github.blog/news-insights/product-news/github-copilot-meet-the-new-coding-agent/)
