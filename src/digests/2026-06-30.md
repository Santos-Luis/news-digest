**Software Engineering & Architecture**

GitHub previewed Claude as an agent provider natively inside JetBrains IDEs, letting developers trigger full agentic coding sessions — multi-file edits, terminal access, MCP tool calls — without leaving IntelliJ or PyCharm. **AI Tools & Developer Utilities**

Anthropic shipped scheduled agent deployments as a generally available feature in Claude Code, enabling agents to run on a cron schedule and autonomously start sessions and complete tasks with no external orchestration layer. Combined with Claude's general availability on Microsoft Azure AI Foundry — bringing Azure-native identity, billing, and governance — the releases mark a concrete step toward enterprise-grade autonomous agent infrastructure that can meet existing security and compliance requirements.
