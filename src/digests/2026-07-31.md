**AI Tools & Developer Utilities**
Anthropic shipped a significant breaking change to the Claude Agent SDK this week: the new `agent-memory-2026-07-22` beta header replaces `managed-agents-2026-04-01` on all memory store endpoints, with updated semantics for result ordering, depth limits, and path prefix matching. All official SDKs (Python, TypeScript, Go, Java, Ruby, PHP, C#) and the CLI have been updated to send the new header automatically — but developers must be aware that old page cursors are invalidated and sending both headers simultaneously returns a 400. The rename signals Anthropic's broader repositioning of the SDK around general agent capabilities rather than code-specific workflows.
