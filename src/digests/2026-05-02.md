**Software Engineering & Architecture**  
Confluent’s move to put Kafka schema IDs in message headers rather than payloads is a quiet but important architecture change: it lets teams add schema governance to existing event streams without rewriting event formats. That should reduce coordination pain across microservices, analytics, Flink, and ML pipelines. [InfoQ](https://www.infoq.com/news/2026/05/confluent-kafka-header-schema-id/)
