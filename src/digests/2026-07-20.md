**Enterprise AI & AI Strategy**

Microsoft launched Microsoft Frontier Company, a new operating business backed by $2.5 billion and 6,000 engineers and industry specialists, explicitly tasked with getting enterprises past the deployment gap — the point where AI adoption stalls before it scales. AWS followed with a $1 billion internal commitment using the same Forward Deployed Engineer model, signaling that the competitive axis in enterprise AI has shifted from model quality to deployment execution. Meanwhile, a striking data point from the field: companies that build AI into their products are being valued at a 130% premium over those using AI only for internal productivity. [Microsoft Frontier Company via TechCrunch](https://techcrunch.com/2026/07/02/microsoft-launches-its-own-ai-deployment-company-with-2-5-billion-commitment/)

**AI Tools & Developer Utilities**

Anthropic shipped three advanced tool use features for the Claude Developer Platform: a Tool Search Tool that lets Claude access thousands of tools without bloating the context window, Programmatic Tool Calling that lets Claude invoke tools inside a code execution environment, and Tool Use Examples as a universal standard for demonstrating tool behavior. The Claude Agent SDK (renamed from Claude Code SDK earlier this year) also hit a new milestone with hierarchical subagents now supported up to three levels deep, reinforcing the platform's positioning as a full agent harness — not just a coding assistant. The broader agent framework ecosystem is seeing its fastest-ever period of production feature shipping, with every major SDK now offering durable state and pluggable backends.
